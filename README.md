# 🌊 Aarunya – Smart Maritime Risk Intelligence System

Aarunya is an AI-powered maritime intelligence platform that enables vessel tracking, weather analysis, and risk prediction in a single interactive dashboard.

---

## 🚀 Live Demo

 Link: https://aarunya-2p3o.vercel.app/

---

## 🧠 Problem

Maritime operations face:
- Unpredictable weather 🌪️  
- Shipment delays ⏱️  
- Lack of decision support 📉  

Existing systems provide data but not actionable insights.

---

## 💡 Solution

Aarunya integrates:
- Ship tracking (AIS-based / simulated)  
- Real-time weather data  
- Risk & delay prediction  
- AI-powered assistant  

All in one dashboard for smart decision-making.

---

## ✨ Features

- 📍 Interactive Ship Tracking  
- 🌦️ Live Weather Insights  
- ⚠️ Risk Prediction (Low / Medium / High)  
- ⏳ Delay Prediction  
- 🤖 AI Maritime Assistant  
- 🚨 Smart Alerts System  
- 📊 Unified Dashboard  
- 🚢 Active Fleet Monitoring  

---

## 🏗️ Architecture

User → Frontend → Backend → APIs/Logic → Response → UI  

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Leaflet
- HTML, CSS, JavaScript

### Backend
- Node.js
- Express.js

### APIs
- OpenWeather API
- Simulated AIS Data

### Deployment
- Vercel (Frontend)
- Render (Backend)

---

## 🧪 Run Locally

### Clone repo
git clone https://github.com/Arindam2005-ctrl/aarunya.git  
cd aarunya  

### Backend
cd backend  
npm install  
node app.js  

### Frontend
cd frontend  
npm install  
npm run dev
